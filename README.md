# About Me

I am a **Software Engineer** with **3+ years of experience** specializing in high-performance backend systems (Go, Java + Spring Boot) and scalable frontend/mobile architectures (React, Flutter & Dart). My background centers on the Latin American **Fintech** sector, where I have designed and integrated critical microservices for real-time credit scoring, secure digital wallets, and automated workflows processing thousands of monthly operations.

In addition to engineering robust production systems, I explore **Agentic AI memory systems**—specifically studying utility, relevance, and budgeted forgetting in Large Language Model (LLM) agents—and **Web3 identity protocols** (Self-Sovereign Identity and verifiable credentials).

# Core Engineering Focus

### ⚙️ Backend Architecture & Fintech

Designing resilient microservices using **Hexagonal and Clean Architectures**. Experienced in implementing secure protocols (SOAP/WS-Security), distributed message queues for contingency fallbacks, and integrating credit bureaus (DataCrédito, TransUnion) and electronic signatures (Deceval).

### 📱 Frontend, Mobile & Security

Developing production-ready, offline-first mobile applications in **Flutter** and responsive web platforms in **React**. Expert in mobile security (secure storage, biometrics, AES-256 local encryption) and building consistent atomic design systems.

### 🧠 Agentic AI & Web3

Researching cognitive architectures for LLM agents, memory retention, and budgeted forgetting. Designing decentralized authentication flows (OAuth2/Auth0) and Self-Sovereign Identity (SSI) components secured on the **Algorand Blockchain**.

# Featured Projects

### [🌐 Cilqum SaaS](https://app.cilqum.online)

A multi-tenant Software-as-a-Service (SaaS) platform built for high concurrency and dynamic user workflows.

*   Architected backend microservices in **Go** to handle session tokens, transactions, and core business logic.
*   Designed and implemented the user interface using **React** for a responsive, interactive user experience.
*   **Tech Stack:** Go (Golang), React, PostgreSQL.

### [🏔️ Pirqa](https://github.com/juancxdev/pirqa)

A modular code generation and scaffolding CLI tool written in **Go**, inspired by the precise dry-stone masonry of Inca architecture.

* Allows developers to build project structures and templates block by block (*rumis*).
* Features compiled **Go hooks** (`pre_gen.go` and `post_gen.go`) executed during generation for dynamic logic.
* **Tech Stack:** Go (Golang), YAML, Text Templates.

### [🧠 BFMA OpenCode Lab](https://github.com/juancxdev/bfma-opencode-lab)

An experimental testbed and evaluation suite for comparing memory management strategies in LLM-driven agents.

* Implements **BFMA** (Budgeted Forgetting Memory Architecture) which scores context items using relevance, importance, recency, and token cost to prune context windows gracefully.
* Generates comprehensive metric dashboards (F1, SubEM, contradictions, latencies) and HTML summary reports for academic and research validation.
* **Tech Stack:** Go (Golang), LLM/OpenCode APIs, JSONL, HTML/CSS.

### [📱 Design System o1](https://github.com/juancxdev/ds_o1)

A reusable atomic design system library for Flutter applications, built to guarantee UI consistency and brand scaling across complex projects.

* **Tech Stack:** Flutter, Dart, Riverpod.
